可视化分析 — 技术说明

⚙ 因子构建方法

本系统采用五因子四象限模型（V5升级），对行业ETF进行截面分析。将RSRS阻力支撑强度、资金流向（Flow）、价格动量（Momentum）、财务质量（F_Quality）和日内效率（IntEff）五个维度标准化后，加权组合为复合因子。

  • RSRS因子 (Resistance Support Relative Strength)：对ETF每日高点和低点做OLS回归（β × R²），衡量支撑/阻力结构稳定度。正值表示趋势结构稳定，负值表示结构不稳定。
  • 资金流因子 (Flow)：对ETF份额数据做EWMA加权回归斜率（半衰期3天），再经横截面Rank标准化。正值为资金流入，负值为流出。
  • 动量因子 (Momentum)：计算过去M日价格收益率，除以同期波动率（60日）进行风险调整。
  • 财务质量因子 (F_Quality)：综合行业成分股的ROE、PB估值分位（反向）、盈利增速三个基本面维度，流通市值加权合成。详见下方财务质量因子说明。
  • 日内效率因子 (IntEff)：基于OHLC代理计算每日价格效率（Eff=当日净变动/日内路径长度），再取Eff 5日SMA上做长短EWMA差值。衡量的是效率水平的动量变化：正值表示效率在提升（趋势在加强），负值表示效率下降（趋势钝化/转为震荡）。详见下方日内效率因子说明。
RSRS = β × R² (High ~ Low, OLS回归, N日窗口)
Flow = EWMA_Slope(份额, N日) → Rank标准化
Mom = Return(M日) / Std(日收益率, 60日)
Eff = |Close(t)-Close(t-1)| / [(High-Low) + |Close-Open|] (OHLC代理)
IntEff = EWMA_short(SMA_5(Eff)) - EWMA_long(SMA_5(Eff))

复合因子 = w_rsrs×Z_rank(RSRS) + w_flow×Z_rank(Flow) + w_mom×Z_rank(Mom)
    + w_quality×Z_rank(F_Quality) + w_efficiency×Z_rank(IntEff)

Z_rank(x) = Z-score(Rank(x)) — 先秩排序再标准化

权重 w_* 因预设而异（详见下方预设参数说明），且财务质量权重会根据市场择时信号在 0.10~0.40 间浮动。

所有因子经Rank秩标准化（标准分排名）处理，比常规Winsorize+Z-Score更适合17只ETF的小样本截面：避免截断1~2只尾部样本带来的统计失真，且对异常值天然鲁棒。

RSRS与动量极低共线性（Pearson < 0.23），提供完全独立的信息增量。

★ 财务质量因子 (F_Quality) — V4新增

V4引入了第四个因子维度——财务质量因子 (F_Quality)，从上市公司财务基本面角度提供横截面筛选能力。该因子由三个子因子等权合成：

  • 最新ROE (F_ROE)：行业成分股最新季度ROE的流通市值加权平均值。衡量行业整体盈利能力。
  • PB估值分位 (F_PB_Pct)：行业成分股最新PB_TTM在5年历史中的估值分位，取反向指标（1-分位数）。低估值（低PB历史分位）得高分。
  • 盈利加速度 (F_Earnings_YoY)：成分股单季度归母净利润同比增长率的行业均值，再做截面Z-Score。反映行业盈利增长动能。
F_Quality = (Z(F_ROE) + Z(F_PB_Pct) + Z(F_Earnings_YoY)) / 3

（注：V4阶段复合因子为四因子等权；V5加入IntEff后改为五因子差异化权重。）

行业成分股映射：每只行业ETF使用10只代表性成分股作为代理组合，优先使用流通市值加权，数据不足时降级为等权。有效成分股少于3只时该行业因子赋值为截面中位数。

数据源：ROE及净利润增速来自 Tushare fina_indicator；PB及流通市值来自 stock_daily_basic。

商品类ETF处理：石油ETF、黄金ETF等商品类不计算财务因子。底层代码实现资产掩码+权重重分配：在复合因子合成时，商品ETF的F_Quality权重被等比例分摊到RSRS/Flow/Mom/IntEff四个技术面因子（除权公式：factor = 技术面加权和 / (1 - w_quality)），确保截面评分在同维度下公平竞技。

容错机制：某只成分股数据缺失则从该期计算中剔除；整个行业有效数据不足3只则该行业因子赋值为截面中位数。

⇄ 日内效率因子 (IntEff) — V5新增

V5引入第五个因子维度——日内效率因子 (IntEff)，从价格运动结构角度衡量趋势的流畅程度。该因子并非直接使用效率绝对值，而是通过效率指标的MACD（长短周期EWMA差值）捕捉效率的变动方向。

  • 底层效率 (Eff)：每日OHLC代理指标，计算当日净变动(|Close(t)-Close(t-1)|)占日内总路径((High-Low)+|Close-Open|)的比例。Eff值高=单边趋势强、噪音低；Eff值低=盘中折返多。
  • 信号平滑：对Eff做可选SMA平滑（短期预设sma=0跳过此步以减少滞后，中/长期预设sma=5做5日均线），消除单日异常波动。
  • 动量化：对平滑后的序列做两个EWMA（半衰期5天和20天），取差值即为IntEff。正值=效率在提升（趋势在增强），负值=效率下降（趋势钝化/转为震荡）。
Eff(t) = |Close(t)-Close(t-1)| / [(High(t)-Low(t)) + |Close(t)-Open(t)|]
Eff_5 = SMA_5(Eff)
IntEff = EWMA(Eff_5, λ=5d) - EWMA(Eff_5, λ=20d)

IntEff经过横截面Rank标准化后参与复合因子合成。因子的核心价值在于识别趋势结构的变化拐点：当IntEff由负转正时提示噪音下降、趋势可能加速；由正转负时提示趋势衰竭风险。

■ 四象限分类模型

根据Z_Flow和Z_Mom的正负号，将ETF分为四个象限：

  • Q1 强势 Z_Flow ≥ 0, Z_Mom ≥ 0 — 资金流入+价格上涨，趋势共振。适合持仓或加仓。
  • Q2 潜伏 Z_Flow ≥ 0, Z_Mom < 0 — 资金流入但价格下跌。左侧布局机会。
  • Q3 撤离 Z_Flow < 0, Z_Mom < 0 — 资金流出+价格下跌。风险最高，建议回避。
  • Q4 风险 Z_Flow < 0, Z_Mom ≥ 0 — 资金流出但价格仍涨。警惕诱多陷阱。

投资含义：投资建议引擎优先从Q1（60%预算）和Q2（40%预算）中筛选候选标的。Q3中RSRS因子>0.3且复合因子>0的品种按信号强度纳入候选（RSRS覆盖机制），Q4始终排除。

● IC (Information Coefficient) 分析

IC衡量因子对未来收益的预测能力。使用Spearman秩相关系数（Rank IC）：

IC = Spearman_Rank_Correlation(T日因子值, T+1到T+1+H日收益率)

前视偏差控制：因子在T日收盘后才可计算（需要T日收盘价和T日份额数据），因此IC分析中用T日因子预测T+1日起的收益，确保无前视偏差。

关键统计量：

  • IC均值：所有日IC的平均值。|IC均值| > 0.03 为显著，表示因子有预测力。
  • ICIR：IC均值 / IC标准差。|ICIR| > 0.05 为弱有效，> 0.10为可用，> 0.20为良好。注意：行业内截面ICIR通常远低于选股领域，|ICIR|能在日频滚动中稳定>0.05即具有实用价值。
  • IC胜率：IC > 0的交易日占比。> 50% 表示因子方向正确，> 60%为优秀。

⚙ 预设参数说明

每个预设定义了五因子参数和差异化权重：

  • 短期：RSRS=20, Flow=10, Mom=20, H=10。权重 RSRS 0.28 / Flow 0.14 / Mom 0.28 / Quality 0.20 / Eff 0.10。
  • 中期：RSRS=20, Flow=20, Mom=60, H=20。权重 RSRS 0.21 / Flow 0.21 / Mom 0.28 / Quality 0.20 / Eff 0.10。
  • 长期：RSRS=30, Flow=40, Mom=120, H=40。权重 RSRS 0.175 / Flow 0.175 / Mom 0.35 / Quality 0.20 / Eff 0.10。
  • RSRS进取：RSRS=15, Flow=10, Mom=10, H=10。权重 RSRS 0.35 / Flow 0.14 / Mom 0.21 / Quality 0.20 / Eff 0.10。

权重动态调整：财务质量权重会根据大盘择时信号在 0.10~0.40 之间浮动（市场偏弱时 quality 降至 0.10，释放更多权重给技术面；超跌反弹时 quality 升至 0.40 加强防御）。

弱市反转模式：当大盘择时信号 < -0.3（偏弱/过热），动量(Mom)因子自动切换为短周期反转信号（5日收益率的负值），使系统在趋势失效时捕获均值回归机会。弱市中的四象限定义变为：Q1=资金流入+价格超跌 和 Q2=资金流入+价格反弹，Q3=资金流出+价格超买 和 Q4=资金流出+价格下跌。

RSRS=回归窗口天数, Flow=份额回溯天数, Mom=动量回溯天数, Quality=财务质量因子, Efficiency=日内效率因子, H=最优预测周期。

⚠ 注意事项

  • 本分析仅供学习研究，不构成任何投资建议。
  • 因子有效性会随市场风格变化而波动，历史IC不代表未来表现。
  • IC分析已采用T+1延迟消除前视偏差，但实际交易还需考虑滑点和冲击成本。
  • 行业ETF数量有限（17只），截面IC统计的样本量较小，结论需谨慎对待。
  • 资金流数据基于ETF份额变化，可能存在申赎套利导致的噪声。
  • 财务质量因子基于行业代表性成分股计算，非ETF实际持仓，存在跟踪误差。成分股每季报后可更新。
  • 财务数据天然滞后（季报披露延迟1-2个月），F_Quality为慢变量，适合中期配置参考。
  • 建议结合基本面分析和市场环境综合判断。
