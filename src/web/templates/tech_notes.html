可视化分析 — 技术说明

⚙ 因子构建方法

本系统采用双因子四象限模型，对行业ETF进行截面分析。核心思路是将资金流向（Flow）和价格动量（Momentum）两个维度标准化后，划分到四个象限中进行分类评估。

  • 资金流因子 (Flow)：对ETF份额变化序列做OLS线性回归斜率。斜率为正表示资金持续流入，为负表示持续流出。
  • 动量因子 (Momentum)：计算过去M日价格收益率，并除以同期波动率进行波动率调整，得到风险调整后的动量。
Flow = OLS_Slope(份额变化, N日回溯)
Mom = Return(M日) / Volatility(M日)

每个ETF的因子值经过截面Z-Score标准化：

Z = (X - mean) / std

最终交互因子 = Z_Flow × Z_Mom，综合反映资金面与技术面的共振程度。

■ 四象限分类模型

根据Z_Flow和Z_Mom的正负号，将ETF分为四个象限：

  • Q1 强势 Z_Flow > 0, Z_Mom > 0 — 资金流入+价格上涨，趋势最强。适合持仓或加仓。
  • Q2 潜伏 Z_Flow > 0, Z_Mom < 0 — 资金流入但价格下跌。可能是左侧布局机会。
  • Q3 撤离 Z_Flow < 0, Z_Mom < 0 — 资金流出+价格下跌。风险最高，建议回避。
  • Q4 风险 Z_Flow < 0, Z_Mom > 0 — 资金流出但价格仍在涨。警惕诱多陷阱。

投资含义：优先关注Q1强势板块，Q2可作为逆向布局候选，Q3/Q4需谨慎。

● IC (Information Coefficient) 分析

IC衡量因子对未来收益的预测能力。本系统使用Spearman秩相关系数（Rank IC）：

IC = Spearman_Rank_Correlation(因子值_t, 未来H日收益率)

每日计算截面IC，形成IC时间序列。关键统计量：

  • IC均值：所有日IC的平均值。|IC均值| > 0.03 为显著，表示因子有预测力。
  • ICIR：IC均值 / IC标准差。|ICIR| > 0.5 为稳定，> 2为非常稳定。ICIR越高，因子预测能力越可靠。
  • IC胜率：IC > 0的交易日占比。> 50% 表示因子方向正确，> 60%为优秀。

⚗ 图表解读指南

1. 因子分布直方图

展示最新一期所有ETF的交互因子（Z_Flow × Z_Mom）分布。横轴为因子值区间，纵轴为ETF数量。

  • 正偏分布 → 整体偏强，多数板块资金+动量共振向上
  • 负偏分布 → 整体偏弱，多数板块资金外流+动量向下
  • 集中分布 → 板块分化小，缺乏结构性机会

2. 四象限收益热力图

展示四个象限在最新日期的平均远期收益（%）。颜色深浅代表收益高低，绿色为正收益，棕色为负收益。

  • 理想状态：Q1收益 > Q2 > Q3 > Q4，说明因子有效区分了优劣板块
  • Q1显著正收益 → 强势板块确实跑赢

3. IC序列曲线

每日IC值的时序变化。棕色虚线为IC均值，浅色虚线为±2σ波动带。

  • IC持续为正 → 因子预测力稳定
  • IC波动剧烈 → 因子不稳定，需谨慎依赖
  • IC趋势性下降 → 因子可能正在失效

4. IC衰减图

不同持有期（1日、5日、10日、20日...）下的IC均值变化。

  • IC随持有期衰减越慢 → 因子在中长期越有效
  • 快速衰减至0 → 因子仅短期有效，适合短线策略
  • 衰减周期 = IC降至0.02以下的持有天数

5. 分组累计收益曲线

四个象限的累计收益率随时间变化。Q1为强势组，Q3为弱势组。

  • Q1曲线持续向上 → 选出的强势板块确实持续跑赢
  • Q1与Q3差距扩大 → 多空对冲空间增大
  • 四条线缠绕 → 因子区分度弱

6. 因子滚动ICIR

60日滚动窗口计算的ICIR。反映因子预测力的动态稳定性。

  • 滚动ICIR > 0.5 的区间 → 因子在该时段表现稳定
  • 滚动ICIR跌破0 → 因子失效区间，需降低因子权重
  • 趋势性变化 → 市场风格可能正在切换

7. 行业配置权重建议图

基于最新因子值，对Q1+Q2象限（强势+潜伏）的ETF按因子绝对值归一化为权重。

  • 权重越高 → 因子越极端，建议超配
  • 仅包含Q1和Q2象限的ETF（潜在买入标的）
  • Q3/Q4象限的ETF不参与配置

⚙ 预设参数说明

系统提供三组预设参数：

  • 短期：N=10日, M=20日。适合验证短线因子信号，远期检验覆盖1/5/10/20日。
  • 中期：N=20日, M=60日。适合中线持仓参考，远期检验覆盖1/5/10/20/40/60日。
  • 长期：N=40日, M=120日。适合长周期趋势判断，远期检验覆盖5/10/20/40/60日。

其中 N 为资金流回溯天数，M 为动量回溯天数。

⚠ 注意事项

  • 本分析仅供学习研究，不构成任何投资建议。
  • 因子有效性会随市场风格变化而波动，历史IC不代表未来表现。
  • 行业ETF数量有限（11只），截面IC统计的样本量较小，结论需谨慎对待。
  • 资金流数据基于ETF份额变化，可能存在申赎套利导致的噪声。
  • 建议结合基本面分析和市场环境综合判断。
