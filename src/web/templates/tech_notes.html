可视化分析 — 技术说明

⚙ 因子构建方法

本系统采用三因子四象限模型，对行业ETF进行截面分析。将RSRS阻力支撑强度、资金流向（Flow）和价格动量（Momentum）三个维度标准化后，加权组合为复合因子。

  • RSRS因子 (Resistance Support Relative Strength)：对ETF每日高点和低点做OLS回归（β × R²），衡量支撑/阻力结构稳定度。正值表示趋势结构稳定，负值表示结构不稳定。
  • 资金流因子 (Flow)：对ETF份额数据做EWMA加权回归斜率（半衰期3天），然后用tanh压缩到[-1,1]。正值为资金流入，负值为流出。
  • 动量因子 (Momentum)：计算过去M日价格收益率，除以同期波动率（60日）进行风险调整。
RSRS = β × R² (High ~ Low, OLS回归, N日窗口)
Flow = tanh(EWMA_Slope(份额, N日) × 3)
Mom = Return(M日) / Std(日收益率, 60日)

复合因子 = w&rgr;&sgr;&rgr;&sgr; × Z(RSRS) + wƒlow × Z(Flow) + w㎙om × Z(Mom)

截面Z-Score标准化经过Winsorize 10%（截断极端值）处理，适应小样本（17只ETF）场景。

三因子权重：各预设权重不同（RSRS 0.3~0.5，Flow 0.2~0.3，Mom 0.3~0.5），详见预设参数说明。因子验证结论：RSRS与动量极低共线性（Pearson < 0.23），提供完全独立的信息增量。在牛市中RSRS+动量组合ICIR可达0.43，远超单因子。

■ 四象限分类模型

根据Z_Flow和Z_Mom的正负号，将ETF分为四个象限：

  • Q1 强势 Z_Flow ≥ 0, Z_Mom ≥ 0 — 资金流入+价格上涨，趋势共振。适合持仓或加仓。
  • Q2 潜伏 Z_Flow ≥ 0, Z_Mom < 0 — 资金流入但价格下跌。左侧布局机会。
  • Q3 撤离 Z_Flow < 0, Z_Mom < 0 — 资金流出+价格下跌。风险最高，建议回避。
  • Q4 风险 Z_Flow < 0, Z_Mom ≥ 0 — 资金流出但价格仍涨。警惕诱多陷阱。

投资含义：投资建议引擎仅从Q1（60%预算）和Q2（40%预算）中筛选候选标的，Q3/Q4始终排除。

● IC (Information Coefficient) 分析

IC衡量因子对未来收益的预测能力。使用Spearman秩相关系数（Rank IC）：

IC = Spearman_Rank_Correlation(T日因子值, T+1到T+1+H日收益率)

前视偏差控制：因子在T日收盘后才可计算（需要T日收盘价和T日份额数据），因此IC分析中用T日因子预测T+1日起的收益，确保无前视偏差。

关键统计量：

  • IC均值：所有日IC的平均值。|IC均值| > 0.03 为显著，表示因子有预测力。
  • ICIR：IC均值 / IC标准差。|ICIR| > 0.5 为稳定，> 2为非常稳定。
  • IC胜率：IC > 0的交易日占比。> 50% 表示因子方向正确，> 60%为优秀。

⚙ 预设参数说明

每个预设定义了三因子参数和权重：

  • 短期：RSRS=20, Flow=10, Mom=20, H=10。权重 RSRS 0.4 / Flow 0.2 / Mom 0.4。短线因子信号验证。
  • 中期：RSRS=20, Flow=20, Mom=60, H=20。权重 RSRS 0.3 / Flow 0.3 / Mom 0.4。中线持仓参考。
  • 长期：RSRS=30, Flow=40, Mom=120, H=40。权重 RSRS 0.25 / Flow 0.25 / Mom 0.5。长周期趋势判断。
  • RSRS进取：RSRS=15, Flow=10, Mom=10, H=10。权重 RSRS 0.5 / Flow 0.2 / Mom 0.3。牛市偏RSRS权重。

RSRS=回归窗口天数, Flow=份额回溯天数, Mom=动量回溯天数, H=最优预测周期。RSRS最优参数经独立验证（全周期最佳 RSRS_N=20, H=10, ICIR=0.128）。

⚠ 注意事项

  • 本分析仅供学习研究，不构成任何投资建议。
  • 因子有效性会随市场风格变化而波动，历史IC不代表未来表现。
  • IC分析已采用T+1延迟消除前视偏差，但实际交易还需考虑滑点和冲击成本。
  • 行业ETF数量有限（17只），截面IC统计的样本量较小，结论需谨慎对待。
  • 资金流数据基于ETF份额变化，可能存在申赎套利导致的噪声。
  • 建议结合基本面分析和市场环境综合判断。
