# 投资建议页设计评审

## 涉及真实交易的风险清单

| # | 风险 | 严重度 | 缓解措施 |
|---|------|--------|----------|
| 1 | **因子失效风险** — ICIR仅为0.35时，仍有约35%的概率预测方向错误 | 🔴 | 每个建议附带置信度标签，ICIR<0.3时建议降仓 |
| 2 | **集中度风险** — 推荐的多只ETF可能高度相关（如银行+证券 r=0.61） | 🔴 | ETF间相关系数惩罚，同一行业群组总权重≤40% |
| 3 | **过拟合风险** — 当前因子在历史数据上表现好，但不保证未来 | 🔴 | 附带衰减曲线，展示因子近期IC趋势 |
| 4 | **无止损机制** — 推荐只给了买入和仓位，没有止损线 | 🟡 | 推荐页面增加"预期止损位"建议 |
| 5 | **市场流动性** — 某些ETF日均成交额低，大额买入冲击成本高 | 🟡 | 推荐中标注ETF日均成交额，大额交易提醒 |
| 6 | **时间错配** — 因子10天最优，但用户可能持有1-3个月 | 🟡 | 按预设分别给出短期/中期/长期建议 |
| 7 | **无风险预算** — 简单按因子得分比例分配仓位 | 🟡 | 改用等风险贡献或风险预算模型 |
| 8 | **幸存者偏差** — 数据只包含仍在交易的ETF | 🟢 | 不构成大问题，ETF清盘风险远低于个股 |

## 改进后的推荐引擎设计

### 核心改进点

```
旧逻辑 (build_weight_recommendation):
  因子得分 → 比例分配仓位
  
新逻辑 (build_investment_recommendation):
  因子得分 + 象限 + ETF间相关惩罚 + 大盘择时 → 风险预算分配 → 仓位
```

### 仓位分配公式

```
1. 初始得分 = factor_score × quadrant_multiplier
   Q1(强势): ×1.0, Q2(潜伏): ×0.7

2. 相关惩罚: 与已选ETF的max_corr > 0.6时, 得分×0.5

3. 总风险预算 = 1.0 (满仓) + market_timing_adjustment [-0.3, +0.3]
   
4. 单ETF仓位上限 = min(25%, 总预算 / ETF数量 + 5%)
   例外: 当只有1只符合时, max=30%

5. 止损建议 = max(-5%, -2 × 近20日ATR%)
```
