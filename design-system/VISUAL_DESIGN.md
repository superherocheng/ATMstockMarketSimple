# ATMstockMarket 复古木质风格 - 视觉设计稿

## 设计概览

### 整体风格
复古木质风格将传统木质美学与现代金融数据展示完美融合,营造温暖、自然、怀旧的投资分析氛围。通过深棕色、原木色、米色等自然木质色调,配合木纹纹理和做旧效果,打造独特的视觉体验。

## 核心设计元素标注

### 1. 色彩应用

#### 主色调
- **深胡桃木色** `#3E2723`: 主要边框、导航栏背景、主按钮
- **栗棕色** `#5D4037`: 卡片边框、分割线、次要元素
- **古铜色** `#8D6E63`: 图标、装饰边框、悬停状态

#### 背景色
- **象牙白** `#FFF8E7`: 卡片背景、内容区域
- **米色** `#EFEBE9`: 页面背景、次要区域
- **浅橡木色** `#D7CCC8`: 表头背景、悬停状态

#### 功能色
- **上涨红** `#C62828`: 涨幅、买入信号
- **下跌绿** `#2E7D32`: 跌幅、卖出信号
- **平盘灰** `#757575`: 无变化

### 2. 木质纹理

#### 页面背景纹理
```css
background-image: 
  repeating-linear-gradient(
    90deg,
    transparent,
    transparent 2px,
    rgba(139, 90, 43, 0.03) 2px,
    rgba(139, 90, 43, 0.03) 4px
  ),
  repeating-linear-gradient(
    0deg,
    transparent,
    transparent 20px,
    rgba(139, 90, 43, 0.02) 20px,
    rgba(139, 90, 43, 0.02) 22px
  );
```

#### 做旧效果
```css
/* 纸张纹理叠加 */
background-image: url("data:image/svg+xml,...");
opacity: 0.03;
```

## 动画效果

### 1. 页面进入动画
```css
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

main {
  animation: fadeInUp 0.6s var(--ease-wood);
}
```

### 2. 卡片进入动画
```css
@keyframes cardEnter {
  from {
    opacity: 0;
    transform: scale(0.95);
  }
  to {
    opacity: 1;
    transform: scale(1);
  }
}

.card {
  animation: cardEnter 0.4s var(--ease-wood);
}

/* 交错动画 */
.card:nth-child(1) { animation-delay: 0.1s; }
.card:nth-child(2) { animation-delay: 0.2s; }
.card:nth-child(3) { animation-delay: 0.3s; }
```

### 3. 按钮点击反馈
```css
.btn {
  transition: all 150ms var(--ease-wood);
}

.btn:active {
  transition: all 50ms var(--ease-wood);
}
```

```css

  outline: none;
  box-shadow: 0 0 0 3px rgba(62, 39, 35, 0.3);
```

### 2. 跳转链接
```html

```

### 3. 色彩对比度
- 所有文本与背景对比度 ≥ 4.5:1
- 涨跌色彩在浅色背景上 ≥ 5:1
- 图标与背景对比度 ≥ 3:1

### 4. 触摸目标
- 所有可点击元素 ≥ 44px × 44px
- 按钮间距 ≥ 8px
- 列表项最小高度 48px
